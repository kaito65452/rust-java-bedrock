# `.pstdr` Language & Toolchain Overview

**`.pstdr`** is a domain-specific language (DSL) and compiler toolchain for **Minecraft Bedrock** supporting both **Modern 2.x** (Bedrock `26.60`, `@minecraft/server 2.11.0`, `@minecraft/server-ui 2.0.0`) and **Legacy 1.x LTS** (Bedrock `1.21.50+`, `@minecraft/server 1.15.0`–`1.19.x`, `@minecraft/server-ui 1.3.0`).

---

## Compilation Pipeline

```text
src/*.pstdr ──▶ pstdr-c (parse + semantic & asset checks) ──▶ BP/scripts/generated/*.js
                                                            ├── build/ts/*.ts
                                                            ├── BP/scripts/main.js
                                                            ├── BP/functions/*.mcfunction (inline mcfunction blocks)
                                                            ├── BP/manifest.json
                                                            └── BP/items|blocks/*.json (component wiring)
```

---

## Input vs. Compiled Output

### `.pstdr` Input

```pstdr
@addon(target = "26.60", api = "2.11.0")

const WAND_ID = "example:wand"

on right click with WAND_ID by player {
    apply speed 2 to player for 5s
    player.actionbar("Boost active")
}
```

### Actual JavaScript Output (`pstdr-c convert`)

```javascript
// Generated by pstdr-c v0.1.0-pre-beta.1 from wand.pstdr (Bedrock 26.60)
import { world } from "@minecraft/server";

const WAND_ID = "example:wand";

world.afterEvents.itemUse.subscribe((ev) => {
    const player = ev.source;
    if (!ev.itemStack || ev.itemStack.typeId !== (WAND_ID)) return;
    player.addEffect("speed", 100, { amplifier: 1 });
    player.onScreenDisplay.setActionBar("Boost active");
});
```

## Toolchain Components

| Component | Binary | Role |
| :--- | :--- | :--- |
| **Compiler & CLI** | `pstdr-c` | Format, type/semantic check, compile to JS/TS, wire JSONs, and audit manifests/assets. |
| **Language Server** | `pstdr-lsp` | Real-time diagnostics, hover docs, code actions, and formatting for editors. |
| **PackStudio** | `packstudio` | Optional companion GUI application. |
